# 🛍️ EcommerceNextJs

A fully functional e-commerce web application built with the MERN stack (Postgress, Express, React, Node.js). Includes user authentication, product listing, shopping cart, and admin dashboard for managing products and orders.

---

## 🧰 Tech Stack

- **Frontend**: React, Redux, Tailwind
- **Backend**: Node.js, Express.js
- **Database**: Postgress 
- **Authentication**: JWT (JSON Web Token)
---

## 📦 Features

### 👤 User Features
- Sign Up / Login / Logout
- Browse Products
- Search & Filter
- Add to Cart
- Checkout and Order
- View Order History

### 🛠️ Admin Features
- Product Management (Add, Edit, Delete)
- User Management
- Order Management
- Dashboard Overview
